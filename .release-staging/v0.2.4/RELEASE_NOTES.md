# Jarnsen Mrs Plugin 0.2.4

Certified release for **ATAK-CIV 5.6.0**.

## Changes since 0.1.0
- Selectable start and target sources
- Edit or remove an existing overlay by tapping it
- Live target dragging and preview behavior
- Improved centered target-line presentation
- Sector color quick selection
- Updated mortar toolbar icon

## Compatibility
- Package: `com.jarnsen.atak.mrs.plugin`
- ATAK requirement: `com.atakmap.app@5.6.0.CIV`
- Plugin version: `0.2.4`
- Release source tag target: `2f194dee11d03ac3a641631a95d20e1514ce2e12`
