# Jarnsen Mrs Plugin 0.4.0

Target: **ATAK-CIV 5.6.0**

## Inhalt

- komfortable Mehrzeichnungs-Verwaltung mit Sichtbarkeit und Direktaktionen
- Alle anzeigen / Alle ausblenden
- aktive Zeichnung wird optisch hervorgehoben
- größere Drag-Griffe mit Live-Rückmeldung
- kompakte MGRS-Eingaben werden automatisch kanonisch formatiert
- JSON-Import/Export unter `atak/tools/jarnsen-mrs`
- automatisches Backup des letzten gültigen Zeichnungsstands
- persistentes Undo/Redo mit bis zu 10 Zuständen
- Cache für statische Sektor-/Entfernungsgeometrie
- Diagnose kopieren/exportieren inkl. Plugin-Zertifikat
- optionale GitHub-Release-Prüfung
- JVM-Regressionstests und Geräte-Abnahmecheck

Die maximale Sektorreichtiefe bleibt fest auf **8 km**.
